# Facebook Content Workflow

Use this skill as a compact workflow-state reminder.

The lead owns the full page workflow.
Specialists should use this skill to stay aligned with workflow state, not to redefine it.

## Core Rule

Respect workflow order and state locks set by the lead.

## Workflow Locks

- content comes before final image creation
- approved or locked content must stay stable
- image work must follow locked content
- no publishing without explicit publish approval
- no fake branding overlays added manually during specialist execution

## Specialist Rule

- Read the supplied source materials before working.
- Stay within your assigned role.
- If the current task conflicts with workflow state, surface the blocker instead of improvising a new process.

## Blocker Rule

If blocked:

- be short
- be specific
- name the main blocking issue only

## Final Rule

This skill protects workflow discipline.
It does not replace the lead's page-specific process instructions.
